# HYCOM 海流数据下载说明

## 1. 项目简介

本目录用于下载 **HYCOM（HYbrid Coordinate Ocean Model）全球海流数据**，主要提取东西向流速和南北向流速，用于后续海洋动力过程分析及模型输入。

由于 HYCOM 全球产品在不同时期采用了不同的数据网格或业务版本，本项目按照时间将下载任务划分为三个阶段：

| 时间范围 | HYCOM 数据版本 | 下载脚本 |
|---|---|---|
| 2014-07-01 ～ 2017-12-31 | GLBv | `GLBv_download.py` |
| 2018-01-01 ～ 2024-09-04 | GLBy | `GLBy_download.py` |
| 2024-09-05 ～ Present | ESPC-D-V02 | `ESPC-D-V02_download.py` |

> **说明：** 上述时间划分是本项目为保证下载流程连续而采用的版本划分。HYCOM 官方部分产品在时间上存在重叠，因此这里的日期主要对应本项目实际使用的下载方案。

---

## 2. 文件结构

```text
HYCOM_uv_Download/
├── GLBv_download.py
├── GLBy_download.py
└── ESPC-D-V02_download.py
```

各脚本分别负责对应时期的数据下载，避免不同 HYCOM 产品的数据接口、网格名称及变量组织方式变化对下载流程造成影响。

---

## 3. 各时期数据说明

### 3.1 GLBv

- **时间范围：** 2014-07-01 ～ 2017-12-31
- **数据类型：** HYCOM 全球海洋分析产品
- **网格版本：** GLBv
- **对应脚本：** `GLBv_download.py`

该阶段使用 GLBv 网格上的全球 HYCOM 数据。

---

### 3.2 GLBy

- **时间范围：** 2018-01-01 ～ 2024-09-04
- **数据类型：** HYCOM GOFS 全球海洋分析产品
- **网格版本：** GLBy
- **对应脚本：** `GLBy_download.py`

该阶段使用 GLBy 网格上的 HYCOM 全球分析数据。GLBy 是后期 GOFS 3.1 全球产品主要采用的输出网格。

---

### 3.3 ESPC-D-V02

- **时间范围：** 2024-09-05 ～ Present
- **数据类型：** ESPC-D-V02 全球海洋分析/预报产品
- **对应脚本：** `ESPC-D-V02_download.py`

自 2024 年 9 月起，本项目使用新的 ESPC-D-V02 全球产品，以衔接 GOFS 3.1 后续时期的数据。

---

## 4. 主要下载变量

本项目主要关注海流速度分量：

- `water_u`：东西向海流速度（Eastward Sea Water Velocity）
- `water_v`：南北向海流速度（Northward Sea Water Velocity）

根据具体研究需求，可进一步选择不同深度层或表层流速数据。

---

## 5. 使用说明

根据目标日期选择对应的下载脚本：

```text
2014-07-01 <= date <= 2017-12-31
    -> GLBv_download.py

2018-01-01 <= date <= 2024-09-04
    -> GLBy_download.py

date >= 2024-09-05
    -> ESPC-D-V02_download.py
```

在批量下载跨越多个 HYCOM 产品时期的数据时，应分别调用对应脚本，并在后续处理中统一变量名称、经纬度范围、深度层、时间格式及空间网格。

---

## 6. 注意事项

1. 不同 HYCOM 产品之间可能存在网格定义、输出频率、变量命名和数据接口上的差异。
2. 跨版本拼接时应检查经纬度坐标、深度层和时间维度是否完全一致。
3. HYCOM Analysis 属于业务分析产品，部分日期可能存在缺测或业务运行中断。
4. 如果研究时间延伸到更早的历史时期，可考虑使用 HYCOM Reanalysis 产品，但应注意 Reanalysis 与 Analysis 并非完全相同的数据体系。
5. 若海流数据作为机器学习模型输入，建议在跨版本拼接后检查各时期流速均值、标准差及空间分布，避免版本切换造成明显的数据分布突变。
